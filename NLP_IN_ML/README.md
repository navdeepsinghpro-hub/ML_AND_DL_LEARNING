# 🧠 NLP Basics - Bag of Words & TF-IDF

This project demonstrates the basics of **Natural Language Processing (NLP)** by converting text into numerical vectors using **Bag of Words (BoW)** and **TF-IDF**. These techniques are widely used in text classification, sentiment analysis, spam detection, and other NLP tasks.

## 🚀 Topics Covered

* Text Preprocessing
* Tokenization
* Stopword Removal
* Stemming
* Bag of Words (CountVectorizer)
* TF-IDF (TfidfVectorizer)

## 🛠️ Technologies Used

* Python
* Pandas
* NLTK
* Scikit-learn
* Jupyter Notebook

## 📚 What I Learned

* How to clean and preprocess text data.
* How to convert text into numerical features using **CountVectorizer** and **TfidfVectorizer**.
* The difference between **Bag of Words** and **TF-IDF**.
